# plans/ — 作業の plan と経緯

> **何かをやるときは plan から始め、その plan（やりたいこと・背景・方針・経緯）を
> 1 ファイルとしてここに残す。** これが「なぜそうしたか」の一次記録になる。

## 運用

- 作業に着手する前に、この配下へ plan を 1 ファイル作る。
- ファイル名は `YYYY-MM-DD-<topic>.md` 程度を推奨（例: `2026-07-13-auth-migration.md`）。
- 中身の目安（決まった様式はない・過不足は自由）:
  - **やりたいこと** — 何を実現するか
  - **背景・なぜ** — その判断に至った理由・前提・却下した案
  - **方針** — どう進めるか（影響範囲・手順）
  - **経緯・メモ** — 途中で分かったこと・決めたこと
- 作業が終わっても**消さない**。経緯・意思決定の記録として残す。
- ざっくりした「やりたいこと」の一覧は `docs/MILESTONE.md`、
  変更履歴は `docs/CHANGELOG.md`、設計の一次情報は `docs/DESIGN.md` に置く。
