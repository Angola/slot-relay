# MILESTONE.md — マイルストーン

> このプロジェクトで「どこまでに何をやりたいか」をざっくり書く場所。
> **区切りは自由**（バージョン / 時期 / フェーズ / テーマ、何でもよい）。完成仕様ではなく、
> **やりたいことのメモ**として気軽に書き足す。詳細な設計は `docs/DESIGN.md`、
> 個別作業の背景・方針は `docs/plans/` に置く。

## 使い方

- 粒度は自由。1 行の箇条書きでも、段落でもよい。
- 達成したら消さずに残し、`✅` などで印を付けてもよい（履歴として読める）。
- 「いつやるか未定」のアイデアは末尾の「## いつか（未定）」に置いておく。

## 1.0 — 自分専用の予約 API（MVP）

Google カレンダー連携の予約 API を Coolify に立て、genba-tsunagu.jp の予約フォームから使えるようにする。

- ✅ 予約メニュー登録 API（管理 API・`X-Admin-Key`）
- ✅ 曜日別受付時間 / 特定日の休業・時間変更
- ✅ 空き枠取得 API（Google FreeBusy・バッファ・最短受付時間・最大予約可能日）
- ✅ 予約登録 API（Idempotency-Key・仮確保・直前確認）
- ✅ Google カレンダーへの予定作成
- ✅ 二重予約防止（`EXCLUDE USING gist` + 同時実行テスト）
- ✅ 予約確認メール / 管理者通知メール
- ✅ キャンセル API（トークン認可・Google 予定の削除）
- ✅ 日時変更 API（管理 API）
- ✅ OpenAPI 3.1 + Swagger UI（`/openapi.json` / `/docs`）
- ✅ Turnstile + レートリミット
- ✅ Dockerfile・ヘルスチェック（`/health` / `/ready`）
- ✅ 予約フォームの参照実装（Next.js）
- ⬜ Coolify へ配備してヘルスチェックが通ることを確認する
- ⬜ PostgreSQL の日次バックアップを設定する
- ⬜ genba-tsunagu.jp の予約フォームから接続する

## 1.x — 運用しながら埋めるところ

- ⬜ キャンセル期限（何時間前まで許可するか）を決める
